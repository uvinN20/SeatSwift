# 🚌 SeatSwift — Smart Bus Booking System

**SeatSwift** is a modern bus reservation platform designed to make bus travel easier, faster, and more convenient. Passengers can explore available routes, book seats, upload payment slips, and track booking confirmations, while administrators manage routes, bookings, and payment verification.

## ✨ Key Features

### 👤 Passenger Features
- User registration and secure login
- Browse available bus routes and schedules
- View bus details and seat availability
- Select seats and book journeys
- Upload payment slips for verification
- View booking details and confirmation status
- Access booking history

### 🛠️ Admin Features
- Manage bus routes and schedules
- Manage bus and seat information
- View and manage passenger bookings
- Review uploaded payment slips
- Confirm or reject payments
- Monitor booking information through an admin dashboard
